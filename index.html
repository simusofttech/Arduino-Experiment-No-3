Arduino Experiment No. 3

Rain Detection Sensor

Aim Components Connections Working Procedure Code Output

Aim

To detect the presence of water using a rain sensor and activate a buzzer when the sensor value crosses a predefined threshold.

About the Experiment

This experiment uses a rain detection sensor connected to the Arduino analog input.

The Arduino continuously reads the analog value from the sensor on pin A0.

When the sensor value becomes greater than 500, the Arduino turns ON the buzzer connected to digital pin 8.

When the sensor value is below the threshold, the buzzer remains OFF.

Procedure

  1. Connect the Arduino UNO to the computer using a USB cable.
  2. Connect the rain sensor analog output to Arduino pin A0.
  3. Connect the rain sensor VCC to 5V.
  4. Connect the rain sensor GND to Arduino GND.
  5. Connect the buzzer positive terminal to digital pin 8.
  6. Connect the buzzer negative terminal to GND.
  7. Open Arduino IDE.
  8. Select Arduino UNO from Tools → Board.
  9. Select the correct COM port.
  10. Enter the Rain Detection program.
  11. Click Verify to compile the program.
  12. Click Upload to upload it to the Arduino.
  13. Open the Serial Monitor and set the baud rate to 9600.
  14. Place water drops on the rain sensor.
  15. Observe the sensor value and buzzer response.

Arduino Code

Rain_Detection.ino 
int sensor = A0; // Rain sensor connected to A0

int buzzer = 8; // Buzzer connected to digital pin 8

void setup() {

    pinMode(buzzer, OUTPUT); // Set buzzer pin as output

    Serial.begin(9600); // Initialize serial communication

}

void loop() {

    int value = analogRead(sensor); // Read sensor value (0-1023)

    Serial.println(value); // Display value on Serial Monitor


    if (value > 500) { // Threshold for water detection

        digitalWrite(buzzer, HIGH); // Turn ON buzzer

    }

    else {

        digitalWrite(buzzer, LOW); // Turn OFF buzzer

    }


    delay(200); // Small delay for stability

}

Code Explanation

int sensor = A0;

Defines analog pin A0 as the input pin for the rain sensor.

int buzzer = 8;

Defines Arduino digital pin 8 as the buzzer control pin.

pinMode(buzzer, OUTPUT);

Configures the buzzer pin as an output.

Serial.begin(9600);

Starts serial communication at 9600 baud so that sensor values can be displayed on the Serial Monitor.

analogRead(sensor);

Reads the analog value from the rain sensor. The Arduino analog input produces values from 0 to 1023.

Serial.println(value);

Displays the current rain sensor reading in the Arduino Serial Monitor.

if (value > 500)

Checks whether the sensor value is greater than the threshold value of 500.

digitalWrite(buzzer, HIGH);

Turns the buzzer ON when the threshold condition is satisfied.

digitalWrite(buzzer, LOW);

Turns the buzzer OFF when the sensor value does not cross the threshold.

delay(200);

Adds a small delay of 200 milliseconds between sensor readings for stability.

Serial Monitor

The rain sensor value is continuously displayed in the Arduino Serial Monitor.

The values can range from 0 to 1023.

Set the Serial Monitor baud rate to 9600.

Expected Output

  • Arduino continuously reads the rain sensor value.
  • The sensor value is displayed on the Serial Monitor.
  • When the sensor reading is greater than 500, the buzzer turns ON.
  • When the sensor reading is below or equal to 500, the buzzer remains OFF.
  • The system continuously monitors the sensor.

Result

The rain detection experiment was successfully implemented using Arduino.

The Arduino reads the analog rain sensor value and activates the buzzer when the value crosses the configured threshold of 500.
